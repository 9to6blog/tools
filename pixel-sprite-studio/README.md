# Pixel Studio

게임용 픽셀 이미지를 만드는 로컬 도구입니다. Next.js App Router + Shadcn UI + sharp를 사용합니다.

## 실행

Windows PowerShell과 Node.js/npm이 필요합니다. Node.js **24.14.1**에서 검증했습니다. 처음 내려받은 PC에서는 아래 순서로 설치·빌드하세요.

```powershell
git clone https://github.com/9to6blog/tools.git
cd tools\pixel-sprite-studio
npm.cmd ci
npm.cmd run build
.\start.ps1
```

이미 저장소를 내려받았다면 `pixel-sprite-studio` 폴더에서 `npm.cmd ci`부터 진행합니다. 의존성 설치와 빌드는 각 PC에서 실행하며, 빌드 산출물은 GitHub에 올리지 않습니다. API 키는 앱 화면에서 입력합니다. 무료 이미지 변환과 시트 분할에는 키가 필요하지 않습니다.

`Start Pixel Studio.cmd` → http://127.0.0.1:3216 . 종료는 `Stop Pixel Studio.cmd`입니다. 생성·변환 중에는 종료하지 마세요. 서버 종료 후에도 `outputs/`의 원본과 결과는 남습니다.

레퍼런스 파일, 생성·변경 프롬프트, 출력 크기·여백·팔레트·모델·품질, 캐릭터 몸/프레임 크기와 동작 선택은 브라우저에 자동 저장합니다. 서버를 종료하거나 페이지를 다시 열어도 같은 브라우저의 같은 주소에서 복원됩니다. 이미지 파일은 IndexedDB, 설정은 localStorage에 보관하며 **API 키는 저장하지 않습니다**. 브라우저 데이터를 삭제하거나 시크릿 창을 닫으면 해당 저장 내용은 사라질 수 있습니다. 저장 오류는 화면에 표시합니다.

설치·빌드 이후에는 위 실행 파일을 더블클릭해 사용할 수 있습니다. PNG·GIF·Aseprite 내보내기는 앱에서 직접 처리하므로 별도 프로그램 설치가 필요하지 않습니다. 내보낸 `.aseprite` 파일을 열고 수정할 때 Aseprite를 사용하세요.

## 레퍼런스 생성 · 비용 계산

새 이미지 생성에 **레퍼런스 최대 4장**과 참고할 요소 설명을 첨부할 수 있습니다. 생성 버튼을 누를 때만 참조가 전송되며, 참조 파일과 설명은 작업 기록 및 ZIP에 보관합니다.

유료 생성 전에는 같은 조건의 이전 사용량으로 예상액을 표시하고, 기록이 없으면 예상 토큰을 직접 입력해 계산할 수 있습니다. 완료 후에는 API 사용량을 공식 단가로 환산해 작업별 비용과 최근 목록 합계를 보여줍니다. USD 기준이며 캐시 할인 미적용·세금 별도입니다. 사용량이 없는 작업은 미산출로 표시합니다. 자세한 범위와 공식 가격 출처는 [레퍼런스·비용 안내](docs/REFERENCES_AND_COSTS.md)를 확인하세요.

## 작업 화면

- **API로 새로 생성**: 설명, 모델, 품질, API 키를 설정하고 유료 생성 버튼을 누릅니다. OpenAI 원본 1장을 생성한 뒤 로컬에서 변환합니다. Flare와 Sunburst를 지원합니다.
- **내 컴퓨터 이미지 변환**: 파일 선택 후 무료 픽셀 변환을 실행합니다. 시점·자세를 바꾸는 **AI 변경 버튼**은 별도로 있으며, 누를 때만 참조 이미지가 OpenAI로 전송되고 요금이 발생합니다.
- **캐릭터 스프라이트**: 정면 이미지에서 좌·우·뒷모습과 걷기·칼질·활쏘기·낚시·도끼질·괭이질·곡괭이질을 생성합니다. 동작마다 정면·왼쪽·오른쪽·뒷모습, 1~16프레임, FPS와 반복을 선택합니다. 재생·프레임 편집과 Aseprite·시트 PNG·GIF·현재 프레임 PNG·개별 PNG 묶음·전체 ZIP을 지원합니다. [캐릭터 사용 안내](docs/CHARACTER_SPRITES.md)

상단 생성 버튼은 스크롤해도 헤더에 고정되며 현재 탭의 작업과 유료·무료 여부를 표시합니다. 기존 게임 모션, 시트 가져오기, 타일셋 탭은 제거했습니다. 이전 생성 파일과 작업 기록은 보존하며 저장된 애니메이션은 캐릭터 화면에서 다시 불러올 수 있습니다.
- 결과 영역의 **저장된 원본을 현재 설정으로 재변환 · 무료**는 현재 선택한 과거 작업의 원본을 사용합니다. 왼쪽에서 새로 선택한 파일과 구분됩니다.

키는 화면의 React 상태에만 유지되며 새로고침하면 없어집니다. 브라우저 저장소나 파일에 자동 저장하지 않습니다. 사용자가 직접 환경 변수 또는 `.env.local`에 `OPENAI_API_KEY`를 설정하는 방식도 지원합니다. 키 확인은 모델 조회이며 이미지 생성 권한·잔액을 보장하지 않습니다.

## 게임용 크기

- 사용자 지정 가로·세로 **1~4096px**, 직사각형 지원. **사방 여백을 더한 최종 파일도 한 변 최대 4096px**입니다.
- 용도 프리셋 27종: 풀·꽃·덤불·나무·바위, 캐릭터, 아이템·가구, 집·한옥·탑, 바닥·효과. 용도 설명과 권장 가로×세로를 표시합니다. 프롬프트는 유지하고 여백 0·지정 크기 1개로 적용합니다.
- 숫자 정사각형 프리셋도 유지: 8, 16, 24, 32, 48, 64, 96, 128, 192, 256, 384, 512, 768, 1024, 1536, 2048, 4096.
- 타일 크기 × 가로·세로 칸 수 계산: 예를 들어 32px × 8×6칸 → 256×192px, 여백 0. 타일 분할 기능은 아닙니다.
- 여백 4일 때 16×16 → 24×24, 256×192 → 264×200. 비율을 유지하며 가운데 배치합니다.
- 기본 출력은 지정 크기 1개. 선택하면 16/32/48/64/128 비교본도 추가합니다. 중복 규격은 제외합니다.
- 최대 색상 2~256, 알파 0/255, 디더링 없음. `trim`은 불투명 영역 기준으로 맞추고 `canvas`는 원본 전체 배치를 유지합니다.
- 로컬 이미지: 정지 PNG/JPEG/WebP, 파일 50MB 이하 및 디코딩 후 16,777,216픽셀 이하. 기존 1536px 사전 축소를 제거했습니다.
- 큰 결과는 축소 미리보기와 1:1 보기를 제공합니다. 게임에는 `sprite-*.png`를 사용하세요.

128px에 복잡한 건물을 넣으면 창문·기와가 합쳐질 수 있습니다. 게임의 타일 수에 맞게 256×192, 512×384 등 충분한 영역을 배정하세요. 작은 원본을 크게 확대해도 새 디테일이 생기지는 않습니다.

## 생성 원본과 후처리

목표 비율에 따라 API 원본은 1024×1024, 1536×1024, 1024×1536 중 하나를 요청합니다. **4096px 출력 지원이 API의 4096px 원본 생성을 뜻하지 않습니다.** 가로/세로 목표는 프롬프트에도 반영됩니다.

참조 이미지의 자세 변경과 캐릭터 동작 생성은 별도 격자 규격을 사용합니다. 각 요청에 원본 자세를 유지하는 **크기 기준 칸 1개**를 넣고, 그 칸으로 계산한 동일 배율·기준 위치를 모든 결과 프레임에 적용합니다. 기준 칸은 최종 결과에서 제외합니다. 칼·도끼를 든 프레임마다 실루엣 전체를 다시 맞추지 않아 도구 때문에 몸 크기가 바뀌는 후처리를 피합니다. 기준 칸을 포함한 API 원본 크기로 예상 비용을 표시하며, 요청 횟수는 동일하고 실제 비용은 반환 사용량으로 계산합니다. AI가 프레임별로 그린 체형 차이까지 완전히 교정하는 기능은 아니므로 겹쳐보기와 재생으로 확인하세요.

공통 변환: 방향 보정 → 선택적 가장자리 흰색 제거 → 알파 이진화 → 영역 선택 → 팔레트 양자화 → 목표 격자 샘플링 → 비율 유지·여백 → PNG. 대표 색상은 셀의 최빈 RGB를 선택하고 실루엣 기준을 적용합니다. 중앙 픽셀 선택은 한 점을 샘플링하며 실루엣 기준을 사용하지 않습니다.

자동 원본 도트 격자 추정, 의미 기반 배경 제거, 창문·눈 우선 보존, 의미별 레이어 분리, Aseprite native tilemap은 구현하지 않았습니다. AI 참조 편집과 입력한 셀 규격에 따른 시트 분할은 지원합니다. 픽셀 변환은 부분 투명도를 이진화합니다.

공통 스타일에서 시점과 방향을 선택하고 프로젝트 RGB 팔레트를 고정할 수 있습니다. 캐릭터·나무·집 예시 미리보기에 시점·방향·팔레트가 즉시 반영됩니다. 이 미리보기는 무료 설정 예시이며 실제 AI 생성 결과는 아닙니다. `현재 시점/방향 유지`는 참조 원본을 따르며 예시에는 기본 RPG 시점·정면을 사용합니다.

## 저장

`outputs/<작업 ID>/`에 `original.png`, `sprite-N.png` 또는 `sprite-WxH.png`, 대응 `preview-*.png`, `job.json`, `sprites.zip`이 저장됩니다. ZIP에는 N개 결과, N개 미리보기, 원본, metadata.json, README.txt가 들어갑니다. 항목 수는 `2N + 3`이며, 레퍼런스 생성은 참조 PNG R장이 추가되어 `2N + 3 + R`입니다.

API 원본은 반환 PNG를 보관합니다. 업로드 원본은 방향 보정 후 PNG로 재인코딩하므로 업로드 JPEG/WebP의 압축 바이트·메타데이터 전체를 보관하는 것은 아닙니다. 원래 사용자 파일은 수정하지 않습니다. 재변환은 이전 원본에서 새 작업을 만들며 기존 결과를 덮어쓰지 않습니다.

예전 작업·파일명·다섯 크기 설정도 호환됩니다. 목록은 최근 100개, 화면에는 10개를 표시하고 이전 출력은 자동 삭제하지 않습니다.

## 개발·검증

```powershell
npm.cmd ci
npm.cmd test
npm.cmd run lint
npm.cmd run build
.\start.ps1
```

진행 중인 작업이 없는지 확인하고 `stop.ps1`로 서버를 종료한 뒤 다시 빌드합니다. 현재 로컬 PC용이며 Docker나 AWS 서버는 사용하지 않습니다.

- 자동 테스트 36개: 기존 변환 외 팔레트 고정, 시트 분할, GIF·Aseprite·RPG Maker, 타일 묶음, 규격형 타일 연결, 가상 API 참조 요청·중복 방지·오류 진단 보존, 다중 레퍼런스 생성과 비용 계산, 3방향 모습·7동작의 참조 요청과 직접 파일 내보내기, 크기 기준 칸 제거·동일 배율 적용·자세 변경 재변환·과거 걷기 무료 보정을 검증합니다. 유료 API를 호출하지 않습니다. 검증 산출물은 각 PC의 `test-artifacts/`에 만들어지며 저장소에는 포함하지 않습니다.
- `node tests/http-animation.mjs`: 무료 시트 가져오기, 애니메이션·타일 ZIP, 기존 사용자 작업 보존을 확인합니다. 유료 API는 호출하지 않으며 생성한 테스트 작업 ID를 보고서에 기록합니다.
- `node tests/http-expanded.mjs`: 실행 중인 로컬 서버에서 무료 업로드·재변환·직사각형 다운로드·ZIP·기존 기록 보존을 확인합니다. 테스트 작업을 실제 outputs에 만들고 ID를 `test-artifacts/http-expanded-report.json`에 기록합니다. 유료 API는 호출하지 않습니다.
- 이전 `tests/http-smoke.mjs`는 구버전 5개 출력 검증용입니다. 키 오류 검사는 명시적으로 잘못된 키를 사용해 서버 환경 키가 있어도 유료 생성으로 이어지지 않습니다.

서버는 loopback에서만 열고 Host/Origin/전용 헤더를 검사합니다. 외부 공개용 로그인이나 사용자 분리는 없습니다. API 자동 재시도는 꺼져 있고 생성 타임아웃은 240초입니다. 요청은 영구 작업 큐가 아니므로 작업 중 종료하지 마세요.

## API 거절 사유 확인

새 생성, 모션, 참조 이미지 편집에서 API 오류가 발생하면 HTTP 상태, 오류 코드, 문제 항목, API 사유와 요청 ID를 화면에 표시하고 해당 `job.json`의 `apiError`에 저장합니다. API 키와 인증 헤더는 저장하지 않으며, 사유에 포함된 키도 가리고 길이를 제한합니다. 예전 실패 기록에는 당시 API 사유가 저장되지 않아 복구할 수 없습니다.

Flare와 Sunburst의 선택은 유지합니다. 참조 편집은 선택 옵션 `input_fidelity=high`를 강제하지 않고 모델의 기본 입력 처리를 사용합니다. 이 호환성 조정만으로 과거 거절 원인을 확정할 수는 없습니다. 다음 요청이 실패하면 새 진단 정보로 원인을 확인하세요. 모델 자동 교체, 자동 재시도, 실패한 묶음의 자동 재개는 하지 않습니다. 수정 검증에는 가상 API를 사용하며 실제 유료 이미지 요청의 성공을 대신 보장하지 않습니다.
