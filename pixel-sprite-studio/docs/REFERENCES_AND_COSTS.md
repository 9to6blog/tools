# 레퍼런스 생성과 비용 계산

## 레퍼런스로 새 이미지 만들기

`API로 새로 생성` → 그릴 내용 입력 → `레퍼런스 이미지 추가` → 참고할 요소 설명 → 생성 버튼을 누릅니다.

- PNG/JPEG/WebP 최대 4장, 전체 업로드 50MB 이하, 한 장당 16,777,216픽셀 이하입니다. 서버에서 정지 이미지 여부를 확인하고 방향 보정·PNG 변환을 수행합니다. 변환한 참조 전체도 50MB 이하로 제한합니다.
- 첨부 순서가 1번부터 표시됩니다. 예: “1번의 얼굴과 의상 유지, 2번의 색감과 도트 스타일 참고”. 개별 이미지를 제거할 수 있습니다.
- 첨부 파일은 생성 버튼을 누를 때 OpenAI에 전송됩니다. 첨부만 하거나 비용 계산기를 사용하는 동안에는 전송하지 않습니다.
- 참조가 있으면 Images edits, 없으면 기존 Images generations를 사용합니다. 결과는 항상 1장이며 모델을 자동 변경하거나 요청을 자동 재시도하지 않습니다.
- 정규화한 참조는 `reference-1.png`부터 보관합니다. `original.png`는 API가 생성한 원본입니다. 작업 정보에 참조 순서·파일명·참고 설명이 남으며 `sprites.zip`에도 참조가 포함됩니다. ZIP 항목 수는 `2N + 3 + R`입니다(N: 변환 규격 수, R: 참조 수).
- 실패한 요청도 저장한 참조를 보존합니다. 작업 기록의 `사용한 레퍼런스`에서 확인할 수 있습니다. 과거 결과를 선택해도 새 요청에 참조를 자동 첨부하지 않습니다.
- 무료 로컬 변환은 참조 생성과 별도입니다. 기존 모션·시점 변경은 기존의 기준 이미지 입력을 유지합니다.

공식 API는 여러 참조 이미지 입력을 지원합니다. 이 앱은 로컬 파일 처리 용량을 제한하기 위해 최대 4장을 제공합니다: [Images edits API](https://developers.openai.com/api/reference/resources/images/methods/edit).

## 생성 전에 예상하기

생성·시점 변경·모션 묶음·프레임 재생성·자유 타일셋 생성의 유료 버튼 앞에 비용 계산이 표시됩니다.

같은 **모델, 품질, API 출력 크기, 작업 종류, 참조 수**로 완료된 작업의 사용량이 있으면 현재 단가로 환산해 평균과 관측 범위를 보여줍니다. 모션은 프레임 수가 아닌 **동작 × 방향의 API 요청 수**를 합산합니다. 모든 요청 조건에 맞는 기록이 없으면 전체 금액을 확정 표시하지 않습니다. 프롬프트 길이와 참조 해상도도 비용에 영향을 주므로 기록의 최대값은 비용 상한이 아닙니다.

기록이 없을 때는 `단가 보기 · 예상 토큰 직접 계산`에서 텍스트 입력·이미지 입력·이미지 출력 토큰을 요청 1회당 가정해 입력할 수 있습니다. 1회 비용과 전체 요청 수를 곱한 비용을 계산합니다. 입력하지 않은 수치는 자동 추정하거나 0으로 채우지 않습니다. 참조가 없을 때는 이미지 입력에 0을 직접 입력하세요.

**GPT Image 2의 해상도·품질별 토큰 계산기를 GPT Image 2.5에 적용하지 않습니다.** 공식 2.5 모델 문서는 해당 계산기가 2.5 소비량을 예측하지 않는다고 명시합니다. 예전 모델의 품질별 고정 금액을 가져와 표시하지 않습니다.

## 생성 후 사용량으로 계산하기

2026-09-17 확인한 두 모델의 표준 USD 단가(100만 토큰당):

| 입력·출력 | Flare | Sunburst |
|---|---:|---:|
| 텍스트 입력 | $5 | $5 |
| 이미지 입력 | $8 | $8 |
| 이미지 출력 | $30 | $30 |

계산식: `(텍스트 입력 × 5 + 이미지 입력 × 8 + 이미지 출력 × 30) / 1,000,000`.

예를 들어 텍스트 100, 참조 이미지 200, 이미지 출력 1,000토큰이면 **$0.032100**입니다. 이는 계산 예시이며 해당 품질의 평균·고정 가격이 아닙니다.

- 반환된 `usage.input_tokens_details`와 이미지 출력 토큰을 사용합니다. 출력 세부 정보가 있으면 이미지 토큰만 계산합니다. 두 모델의 텍스트 출력은 과금하지 않습니다.
- **캐시 할인 미적용, 세금 별도인 표준 단가 환산**입니다. 실제 청구서 확정액과 다를 수 있습니다. 공식 캐시 입력 가격은 텍스트 $1.25, 이미지 $2이지만, 앱은 입력별 캐시 사용량을 추정해 차감하지 않습니다.
- 계산 결과, 토큰별 내역, 적용 단가 날짜를 작업의 `job.json`에 저장합니다. 이미지가 누락되거나 후처리에 실패해도 이미 반환된 사용량은 보존합니다.
- 과거 작업에 저장한 사용량이 충분하면 현재 단가로 계산할 수 있습니다. 이미 저장된 비용은 당시 값을 유지합니다.
- 사용량 누락·불완전·알 수 없는 모델은 `미산출`입니다. 실패나 응답 중단을 비용 0으로 취급하지 않습니다. 최종 비용은 OpenAI 사용량/청구 화면에서 확인하세요.
- `API 비용 기록`의 합계는 현재 불러온 **최근 최대 100개 로컬 작업 중 산출 가능한 작업만** 포함합니다. 미산출 건수도 표시하며, 계정 전체 누적 비용은 아닙니다.
- 출력 비교 PNG 여러 개를 만드는 작업이나 무료 재변환은 로컬 처리이므로 이미지 생성 요청 수에 곱하지 않습니다.

단가 출처: [Flare](https://developers.openai.com/api/docs/models/gpt-image-2.5-flare), [Sunburst](https://developers.openai.com/api/docs/models/gpt-image-2.5-sunburst). 가격은 자동 갱신하지 않으며 `src/lib/pricing.ts`의 날짜와 단가를 함께 관리합니다.

## 검증

`npm.cmd test`, `npm.cmd run lint`, `npm.cmd run build`로 검증합니다. `tests/generation-references.test.ts`는 가상 API로 실제 SDK multipart 직렬화·참조 순서·파일 보존·ZIP·중복 방지·실패·이전 JSON 요청 호환을 확인합니다. `tests/pricing.test.ts`는 단가·누락 사용량·출력 세부 정보·기록 조건별 매칭·묶음 합산을 확인합니다.

가상 API 테스트는 실제 모델 접근 권한, 잔액, 유료 생성 성공이나 참조 재현 품질을 보장하지 않습니다. 테스트는 실제 유료 API를 호출하지 않습니다.
