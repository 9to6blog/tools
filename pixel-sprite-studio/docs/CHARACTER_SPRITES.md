# 정면 이미지에서 캐릭터 스프라이트 만들기

`캐릭터 스프라이트` 탭 하나에서 방향별 모습, 동작 시트 생성, 재생과 내보내기를 진행합니다. 기존 게임 모션·시트 가져오기·타일셋 화면은 제거했습니다. 이미 생성한 원본과 결과는 삭제하지 않습니다.

## 1. 정면 원본

- PNG·JPEG·WebP 정면 이미지 한 장을 추가하거나 저장된 결과를 고릅니다. 얼굴부터 발끝까지 보이는 원본을 권장합니다.
- 프레임 가로·세로와 그 안의 몸 크기를 설정합니다. 기본 프레임은 96×96px, 몸은 32×48px입니다. 몸을 유지하면서 도구가 움직일 여유를 남겨주세요.
- 공통 스타일의 시점·팔레트를 적용합니다. 캐릭터의 방향은 이 화면의 모습·동작 카드에서 선택합니다.
- 정면 이미지를 선택하는 것만으로 API를 호출하지 않습니다. 상단 고정 생성 버튼을 눌렀을 때 생성합니다.

## 2. 모습과 동작

- 기본 선택은 왼쪽·오른쪽·뒷모습, 각 1장입니다. 같은 규격의 정면 결과도 필요하면 정면을 추가 선택합니다.
- 걷기, 칼질, 활쏘기, 낚시, 도끼질, 괭이질, 곡괭이질을 지원합니다. 각 동작에서 정면·왼쪽·오른쪽·뒷모습을 선택합니다.
- 동작마다 1~16프레임, 1~60 FPS, 반복 여부를 설정합니다. 1프레임은 정지 포즈용입니다.
- `걷기 4방향`은 다른 선택을 해제하고 걷기 4개만 선택합니다. `모든 동작 4방향`은 7개 동작×4방향을 선택하며 모습 선택은 유지합니다.
- 모습 하나 또는 동작·방향 하나당 API 1회입니다. 총 요청 수와 프레임 수, 같은 조건의 사용량 기록에 따른 예상 비용을 표시합니다. 실제 비용은 각 응답 사용량으로 계산합니다.
- 모든 선택의 크기·프레임·FPS를 첫 유료 요청 전에 검사합니다. 순차 실행하며 `현재 요청 이후 중단`은 실행 중인 1회를 마친 뒤 멈춥니다. 오류 발생 시 완료된 결과를 보존하고 자동 재시도하지 않습니다.
- 모든 요청은 같은 정면 원본을 참조합니다. 자동 팔레트일 때 첫 결과의 색상을 이번 묶음에서 공유합니다. 단순 좌우 반전 방식이 아닙니다.

## 3. 재생·편집·내보내기

생성 결과는 아래 편집 목록에 추가됩니다. `저장된 결과 추가`에서 과거 결과도 다시 불러올 수 있습니다. 목록과 프레임 편집은 현재 브라우저에 저장하며 원본 파일은 PC의 `outputs/`에 보존합니다.

- 재생·일시 정지, 이전·다음, 프레임 선택, 배율, FPS·반복 설정
- 프레임 순서 변경, 복제·제외, X/Y 위치, 프레임별 시간, 타격 시점 표시
- **Aseprite**: 현재 동작 `.aseprite` 직접 다운로드. 프레임별 시간과 동작 태그 포함
- **시트 PNG**: 현재 동작의 투명 PNG 격자 시트
- **GIF**: 현재 동작의 재생 GIF
- **현재 프레임 PNG**: 선택한 프레임 1장, 위치 편집 적용
- **각 프레임 PNG 묶음**: 현재 동작의 각 프레임을 `000.png`부터 담은 ZIP
- **현재 동작 ZIP**: 현재 동작의 모든 형식
- **전체 ZIP**: 목록의 모든 동작, 통합 PNG, 동작별 PNG·GIF, 개별 프레임, 통합 Aseprite와 메타데이터

내보내기는 무료이며 API를 호출하지 않습니다. 전체 ZIP은 같은 프레임 크기의 결과를 최대 128개 동작·512프레임·16,777,216픽셀까지 담습니다. GIF는 최대 256색(투명 포함), 10ms 시간 단위여서 PNG/Aseprite와 표현이 조금 다를 수 있습니다. Aseprite 파일의 픽셀 레이어는 1개이며 부위별 자동 분리는 아닙니다.

AI의 방향·외형·시트 격자·동작 일관성은 생성 결과를 재생해 확인해야 합니다. 모의 API 검증은 요청·후처리·내보내기 경로를 확인하며 실제 모델의 미술 품질을 보장하지 않습니다.
